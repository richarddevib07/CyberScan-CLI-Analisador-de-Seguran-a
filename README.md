# 🔐 CyberScan CLI

O CyberScan CLI é um projeto desenvolvido em JavaScript utilizando Node.js, com o objetivo de analisar a segurança de senhas diretamente pelo terminal.

### Funcionalidades
- Análise de força de senhas.
- Identificação de possíveis fragilidades.
- Sistema de pontuação de 0 a 100.
- Classificação de segurança.
- Relatório com recomendações.

### Tecnologias
- JavaScript
- Node.js
- Readline

### Como executar

```bash
node src/scanner.js
```

### Objetivo

Projeto desenvolvido para praticar lógica de programação, manipulação de strings, estruturas condicionais e desenvolvimento de ferramentas voltadas à cibersegurança.
